# 医院信息中心每日英语出词

日期：2026-09-14  
状态：待实现

## 背景

医院信息中心约 60 人，工作日做英语学习：周一到周四出 10 个实用词，周二到周五早上现场抽背。抽人由已有程序完成，本系统只负责出词和展示，不记对错、不登录、不设管理页。

## 目标

科室在内网打开一个地址，按东八区自动看到「该抽背的词」或「当天新词」。词库预先写进项目，服务器不调用大模型。

## 非目标

- 抽人、点名、排班
- 答题、打分、统计、个人进度
- 登录、口令、管理后台
- 运行时调用大模型或外部词典
- 推送、短信、企业微信通知
- 法定节假日调休（按自然周一二三四五，不跳过假期）

## 使用规则

时区固定 `Asia/Shanghai`。

**学习日**：周一至周四。每个学习日 09:00 起，展示该日 10 个新词（全文可见）。

**抽背日**：周二至周五。08:00 起可抽背「最近一个已出词的学习日」那 10 个词：

| 打开时刻 | 主内容 |
|---|---|
| 周一 00:00–08:59 | 今日无新词、无抽背；可看历史 |
| 周一 09:00 之后 | 周一新词 |
| 周二至周四 00:00–07:59 | 仍可看历史；未到抽背时间，不把抽背当作主内容 |
| 周二至周四 08:00–08:59 | 今日抽背 = 昨天 10 词 |
| 周二至周四 09:00 之后 | 当天新词（抽背已过，不再占主屏） |
| 周五 00:00–07:59 | 可看历史 |
| 周五 08:00 之后 | 今日抽背 = 周四 10 词；周五不出新词 |
| 周六、周日 | 无新词、无抽背主内容；可看历史 |

「最近一个已出词的学习日」：周二抽周一，周三抽周二，周四抽周三，周五抽周四。

## 页面

单页应用，手机和电脑同一套布局。无登录。

### 主屏

页眉：`信息中心 · 每日英语`，以及当天日期与星期。

- **新词模式**（学习日 09:00 后）：标题「今日新词 · 10 词」，10 张卡片全部展开：单词、音标、中文释义、英文例句、例句译文。办公词与信息化词混排，不分组。
- **抽背模式**（抽背窗口内）：标题「今日抽背 · 10 词」，整组 10 个列出，不拆成两组。每张卡片默认显示单词、音标、英文例句；中文释义和例句译文隐藏。点击该卡片后显示中文；再点可收起。各卡片独立。
- **空闲模式**：简短说明「今日无新词」或「未到抽背时间」，并提供历史入口。

历史入口始终可用。历史列表按日期倒序，点开某日以新词模式展示（中文直接可见），便于复习，不使用抽背隐藏。

### 词卡片字段

| 字段 | 新词 | 抽背未点开 | 抽背已点开 |
|---|---|---|---|
| 单词 | 显示 | 显示 | 显示 |
| 音标 | 显示 | 显示 | 显示 |
| 中文释义 | 显示 | 隐藏 | 显示 |
| 英文例句 | 显示 | 显示 | 显示 |
| 例句译文 | 显示 | 隐藏 | 显示 |

## 词库

预先生成并随项目发布，覆盖 **2026-09-14 至 2027-09-09** 全部周一至周四（52 周 × 4 天 = 208 个学习日，每天 10 词）。

用当前对话额度在实现阶段写入仓库，运行时只读本地文件。

### 内容要求

- 难度：职场常用，能当场口头用；避免偏僻考试词。
- 配比：每个学习日必须 5 个 `office`（办公沟通）+ 5 个 `it`（医院信息化：HIS/EMR、网络、运维、项目、安全、数据等）。
- 一年内 `word` 不重复（大小写不敏感；缩写如 EMR、HIS 各只出现一次）。
- 例句要短、能在科室场景说出口。
- 音标使用 IPA。

### 存储

每个学习日一个文件：`data/words/YYYY-MM-DD.json`。

```json
{
  "date": "2026-09-14",
  "words": [
    {
      "word": "deploy",
      "phonetic": "/dɪˈplɔɪ/",
      "meaning": "部署",
      "example": "We will deploy the patch tonight.",
      "exampleZh": "我们今晚会部署这个补丁。",
      "category": "it"
    }
  ]
}
```

`category` 仅为 `office` 或 `it`，页面不展示该字段。

超过词库最后一天：主屏提示「词库已用完，需要再生成一批」，历史仍可打开已有日期。

## 结构

一个 Node.js HTTP 服务：

- `GET /`：前端页面
- `GET /api/today`：按服务器东八区当前时间返回主屏状态（`learn` | `recite` | `idle`）及对应词表；词库用尽时带明确错误码
- `GET /api/history`：已有学习日日期列表（倒序）
- `GET /api/day/:date`：指定学习日完整词表（校验 `YYYY-MM-DD` 且确有文件）

密钥、账号、管理页都不需要。配置仅：`PORT`（默认 3000）、监听 `0.0.0.0` 便于内网访问。

部署：`Dockerfile` + 可选 `docker-compose.yml`，也可在服务器上直接 `node` 启动。数据文件打进镜像或挂载均可，默认随仓库一起发布。

## 关键逻辑

`today` 的判定只用服务器时钟，不用浏览器本地时区。

```
now = Asia/Shanghai
weekday, hour = now

if weekday in Mon–Thu and hour >= 9:
    mode = learn, date = today
else if weekday in Tue–Fri and hour >= 8:
    mode = recite, date = previous learning day
else:
    mode = idle
```

`previous learning day`：周二→周一，周三→周二，周四→周三，周五→周四。

## 异常

| 情况 | 行为 |
|---|---|
| 词库缺少某学习日文件 | 该日 API 返回 404；主屏说明「这一天没有词」 |
| 已过 2027-09-09 的学习日 09:00 | 主屏「词库已用完，需要再生成一批」 |
| 非法日期参数 | 400 |
| 服务未启动 | 浏览器连不上，不另做客户端假数据 |

不在运行时自动补词。词库用尽后由开发再生成一批文件。

## 校验

- 用固定时间点测 `/api/today`：周一 8:59 idle、周一 9:00 learn、周二 7:59 idle、周二 8:00 recite（周一词）、周二 9:00 learn（周二词）、周五 8:00 recite（周四词）、周六 idle。
- 抽背页中文默认不可见，点击后可见，再点收起；新词页与历史页中文默认可见。
- 词库：208 个学习日、每日 10 词、每日恰好 5 个 `office` 与 5 个 `it`、全年 `word` 不重复（大小写不敏感）。
- 手机宽度与桌面宽度均可完整阅读卡片、点开抽背。
